# Docker Projects 

## Docker Commands

- Build Image 
```bash
    docker build -t simple_form .
```
- Run Image
```bash
    docker run simple_form
```
- Tag Image
```bash
    docker tag my-app:latest <your-username>/my-app:v1
```
- Push Image to docker Repo
```bash
    docker push <your-username>/my-app:v1
```
